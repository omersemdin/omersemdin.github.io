# omersemdin.github.io

Kişisel portfolyo sitesi — https://omersemdin.github.io

## Düzenleme
- **İçerik:** `index.html` (uygulama, otomasyon kartları, iletişim bilgileri)
- **Renkler / görünüm:** `style.css` en üstteki `:root` değişkenleri
- **Etkileşimler:** `script.js`

Yeni bir otomasyon eklemek için `index.html` içindeki bir `<article class="card auto">` bloğunu kopyalayıp düzenleyin.
`data-cat` değeri filtre butonlarıyla eşleşmeli (`rapor`, `veri`, `bildirim`).
