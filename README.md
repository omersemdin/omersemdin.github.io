# omersemdin.github.io

Ömer Buğra Şemdin — kişisel portfolyo ve blog sitesi · https://omersemdin.github.io

## Dosyalar
| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Ana sayfa: mobil uygulama, otomasyonlar, IoT & DIY, iletişim |
| `blog.html` | Blog sayfası (yazılar `posts.js` dosyasından okunur) |
| `posts.js` | **Blog yazıları burada** — yeni yazı eklemek için listenin başına bir blok ekleyin |
| `style.css` | Görünüm; renkler en üstteki `:root` bölümünde |
| `script.js` | Filtreler, animasyonlar, blog sayfası |

## Sık yapılanlar
- **Yeni otomasyon / IoT projesi:** `index.html` içinde bir `<article class="card auto">` bloğunu kopyalayıp düzenleyin. `data-cat` değeri filtre butonlarıyla eşleşmeli.
- **Yeni blog yazısı:** `posts.js` içindeki bir yazıyı kopyalayıp listenin en üstüne yapıştırın; `id`, `baslik`, `tarih`, `kategori` (`gezi` / `spor`) ve `icerik` alanlarını değiştirin.
